# 大富翁

面對面用手機連線的台灣版大富翁，純網頁、放在 GitHub Pages 就能玩。

- **連線對戰**：房主建立房間後會拿到 4 位數房號，其他人輸入房號加入（2–6 人）。房主的手機就是遊戲主機，負責所有規則判定；連上之後資料是手機之間直接傳（WebRTC / PeerJS）。
- **單機輪流玩**：一支手機輪流傳著玩，會自動存檔。
- **政策卡**：停在政策格、公園或剛好停在起點可以抽政策卡（振興三倍券、TPASS 通勤月票、社會住宅、禮讓行人等 10 種），手上最多 3 張、每回合限用 1 張。

## 部署
1. 把 `index.html` 上傳到 public repo 的根目錄
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`
3. 等一兩分鐘，打開 `https://<帳號>.github.io/<repo>/`

## 注意
- 配對時需要網路（使用 PeerJS 免費配對伺服器），同一個 Wi‑Fi 或熱點最穩定。
- 遊戲中房主請保持畫面開著；房主離開遊戲就會結束。
- 玩家斷線後重新打開網頁、輸入同一個房號就能回到遊戲；斷線期間房主可以代打。
